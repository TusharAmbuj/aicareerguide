## What Figma is

Figma is a collaborative design environment for interfaces, prototypes, design systems, and product handoff.

## Best use cases

- Web and mobile interface design
- Prototyping user flows
- Building reusable design systems
- Reviewing product work with a team

## Why developers should care

Understanding spacing, hierarchy, component states, and interaction patterns helps engineers translate designs into robust responsive interfaces.

## Strengths and limitations

Figma is strong for collaboration and rapid iteration. A design file is not a production implementation, so accessibility, responsive behavior, performance, and maintainability still need to be solved in code.
