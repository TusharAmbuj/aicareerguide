## What GitHub Copilot is

GitHub Copilot provides AI-assisted coding inside developer workflows. It can help generate code, explain existing code, suggest tests, and reduce repetitive implementation work.

## Best use cases

- Boilerplate and repetitive implementation
- Exploring unfamiliar APIs
- Drafting tests and documentation
- Understanding unfamiliar code

## Use it responsibly

Review generated code for correctness, security, complexity, licensing implications, and maintainability. Strong engineering judgment remains essential.

## Strengths and limitations

The main benefit is workflow integration. The main limitation is that generated code can be plausible but wrong, inefficient, or unsafe.
