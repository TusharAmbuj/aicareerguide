## How to use this roadmap

Learn the core data structures, recognize algorithmic patterns, then train under realistic constraints. Use virtual contests and upsolving to turn mistakes into pattern recognition.

## What this path optimizes for

Independent problem solving, complexity awareness, and speed without sacrificing correctness.

## Progress rule

Prefer fewer problems solved deeply over large counts solved mechanically.
