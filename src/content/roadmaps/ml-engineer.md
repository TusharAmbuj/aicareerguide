## How to use this roadmap

Start with Python and data work, then build mathematical intuition, classical ML, evaluation skills, deep learning, and production ML. Use the visual checkpoints as the main interface.

## What this path optimizes for

Correct experimentation, reliable evaluation, production thinking, and the ability to explain model trade-offs.

## Progress rule

Prioritize the core checkpoints. Pick a specialty only after you can complete an end-to-end ML workflow.
